# 🛡️ RPG Graphical Edition

Un semplice e divertente gioco di ruolo (RPG) con interfaccia grafica (GUI) sviluppato in Python utilizzando la libreria `tkinter`. Esplora il mondo, raccogli oggetti unici e combatti contro mostri stravaganti!

---

## 🎮 Caratteristiche del Gioco
- **Interfaccia Grafica intuitiva:** Gestisci il tuo eroe tramite comodi pulsanti.
- **Sistema di Esplorazione:** Trova casualmente oggetti e strumenti utili per la tua avventura.
- **Battaglie Dinamiche:** Affronta una lista variegata di mostri (dai classici Goblin ai temibili *Windows Update*!).
- **Crescita del Personaggio:** Sconfiggi i nemici per aumentare di livello e potenziare il tuo eroe.

## 🚀 Come Giocare (Versione Eseguibile `.exe`)
Se stai utilizzando la versione compilata:
1. Scarica o posiziona il file `.exe` del gioco sul tuo computer.
2. Doppia clic sul file per avviarlo.
3. Clicca su **🔍 Esplora** per trovare oggetti o su **⚔️ Combatti** per affrontare i mostri!

---

## 💻 Requisiti e Installazione (Per sviluppatori)
Se invece vuoi eseguire il codice sorgente in Python:

1. Assicurati di avere Python installato sul tuo PC (include già `tkinter`).
2. Clona o scarica questo repository.
3. Esegui lo script con il comando:
   ```bash
   python GPG-Game.py
